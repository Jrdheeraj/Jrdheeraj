## 🧭 About Me

<img align="right" width="300" src="https://raw.githubusercontent.com/abhisheknaiidu/abhisheknaiidu/master/code.gif" alt="Developer Illustration" />

I'm **Dheeraj** — a final-year Computer Science student who splits time between building AI systems in code and building a company in the physical world.

- 🎓 B.Tech CSE, Viswam Engineering College — Class of 2027
- 🏗️ **Founder & CEO, [OxyWalls](#-oxywalls--founder--ceo)** — AI-integrated smart air purification, IoT sensor networks & automated vertical green walls. MSME-funded, AIC-incubated.
- 🧠 Currently deep in **AI/ML systems** — knowledge graphs, agentic RAG, and multi-agent orchestration
- 🏆 Led 5 hackathon teams as sole technical contributor; runner-up at Ignite 8.0, 2nd Best Innovation Award (AIC)
- ⚡ I ship first, refine relentlessly, and I'm comfortable owning both the hardware and the software stack

### 🧩 RepoMind
**AI-powered codebase intelligence platform**

An agentic system that understands entire codebases the way a senior engineer does — mapping structure into a knowledge graph and reasoning over it instead of just embedding chunks of text.

- 🕸️ **Neo4j knowledge graphs** built from AST-level code parsing
- 🔍 **Hybrid RAG** (Qdrant/FAISS) for structural + semantic retrieval
- 🤖 **LangGraph multi-agent system** for multi-step reasoning over a repo
- 💰 Designed with a monetization API layer from day one

`Python` `Neo4j` `LangGraph` `Qdrant` `FastAPI`

</td>
<td width="50%" valign="top">

### 🔎 TruthLens AI
**Multimodal fact-verification platform — live**

An Agentic RAG pipeline that cross-verifies claims against live web and encyclopedic sources and returns a strict verdict — no hedging, no hallucinated nuance.

- ⚙️ Agentic RAG orchestration on **Groq LLM**
- 🌐 Live retrieval via DuckDuckGo & Wikipedia
- 🧱 **FastAPI + React/TypeScript** end-to-end
- ✅ Deployed live on Vercel, public repo

`FastAPI` `React` `TypeScript` `Groq` `Agentic RAG`

</td>
</tr>
